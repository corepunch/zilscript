1 PUSH breaker -> north opens, no timer. Examination identifies the push reset; open/turn attempts remain safe.
2 wrench + pump -> restored cooling. TURN pump WITH wrench; wrong tool explicitly rejected, tool must be held and accessible. Repeat safe. Cooling stabilizes all later storage.
3 recorder + strip + comparator -> proof of four physical crew despite five remembered biographies. OPEN recorder, TAKE strip, COMPARE strip WITH comparator. Comparing before taking or using a wrong comparator has no progress. Witness foil never changes.
4 spool + bus + shears -> isolate signal without arcing. FIT spool TO bus, CUT bus WITH shears. Cut before termination or wrong tool yields explicit safe refusal. Isolation opens the receiver and allows core access once proof exists.
5 OPEN receiver, TAKE wafer. Carrier gone but recollections remain: evidence that memory is physically ordinary after implantation. Recoverable object, no consumable.
6 SHOW strip TO Ivo after comparison -> informed crew consent. Before proof Ivo rejects conclusions; repeated evidence cannot multiply consent. Optional NPC topics alter after isolation.
7 PUT wafer IN cold archive with cooling -> sealed sample; PUSH beacon with proof, consent, isolation and sealed sample -> evacuation prepared. Wafer can be retrieved until commitment; final checks use actual containment.
8 PRESERVE console or ERASE console -> explicit terminal ending, both reference physical crew and missing fifth person, different obligations for future rescuers. Neither action accepted before all safety conditions.

Ten common approaches per fixture: EXAMINE, READ, TAKE, OPEN, CLOSE, PUSH, TURN, TURN WITH wrench, CUT WITH shears, PUT strip IN fixture. Selective handlers allow honest substrate fallback; special failures explain relevant order and tool role. No finite resource, timer, locked-away tool, mandatory carried loadout, or irreversible preparation. Repeated flags idempotent. Drop/retrieve is always possible. All commands use registered syntax and explicit scope.
