# Stage 4 progressive hints
Vane: Who is holding it? -> Rook likes bright things -> Search Laundry apron -> GIVE BUTTON TO ROOK; TURN VANE.
Gutter: Look at roots -> Scoop without pulling -> Kitchen has a spoon -> DIG GUTTER WITH SPOON.
Report: Paper can be relaxed -> Warm damp air -> Kitchen kettle -> STEAM REPORT OVER KETTLE; READ REPORT.
Noise: Cloud cannot finish words -> Soften clapper -> Ribbon from apron -> TIE RIBBON TO CHIME.
Trust: Listen first -> Yesterday is evidence, not an accusation -> SHOW REPORT TO CLOUD -> ASK CLOUD ABOUT PAUSE; TELL CLOUD ABOUT PROMISE.
Forecast: Promises need public words -> Carry your card to Mica -> WRITE CARD; GIVE CARD TO MICA -> PUT CARD IN SLOT.
Final: Choose a size of rain -> Terrace cloud -> DRIZZLE CLOUD or SHOWER CLOUD.
